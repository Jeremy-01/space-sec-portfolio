# 伦理与法律边界

**在开展任何 RF 或安全分析工作前，先读完本文件。**

## 硬红线（绝不跨越）
1. **只接收，不发射**：RTL-SDR 是纯接收设备。绝不向卫星或任何空间链路发射信号。
2. **不干扰**：绝不做任何可能干扰真实卫星链路、地面站或 GNSS 服务的操作。
3. **只在授权环境做攻击**：漏洞利用、比特翻转、重放等主动技术，只在 CTF、自有设备、或明确授权的仿真/数字孪生环境中进行。
4. **不攻击未授权系统**：不对任何真实在轨卫星、真实地面站、他人系统实施攻击或未授权访问。

## 被动接收的合规性
- 接收公开广播的卫星信号（NOAA APT、业余卫星遥测）在多数地区合法，但**频段与用途受本地无线电法规约束**——动手前确认所在地规定。
- 业余无线电卫星遥测通常明确开放接收；气象卫星云图为公开广播。
- 不公开、不转售、不滥用任何偶然接收到的敏感或加密内容。

## 安全分析的边界
- 阶段 C 的分析**限于被动观测 + 仿真**：判断某链路是否加密/认证、重放在理论上是否可行、GNSS 欺骗的可行性边界。
- **不实施**主动攻击来"验证"漏洞。用文献、协议规范和仿真来论证，明确区分"已验证"与"推断"。

## 负责任披露
- 若分析中发现真实系统的疑似漏洞，走**负责任披露**流程（联系厂商/CERT），不公开 0day、不做武器化 PoC。

## 一句话原则
> 做防御者的研究，不做攻击者的行动。所有产出都应能坦然放进求职作品集、经得起雇主与同行审视。
