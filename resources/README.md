# 资源清单

已核实真实可用的资源（截至 2026-07）。

## 空间安全 CTF / 竞赛
- [Hack-A-Sat](https://hackasat.com/) — 美太空军 CTF（2020–2023 收官），往届题目开源可练
- [ESA Ctrl+Space CTF](https://security4space.esa.int/2025/ctrl-space-ctf/) — 接棒者，在真在轨卫星上做题，对独立选手友好
- DEF CON Aerospace Village — 空间安全社区与活动枢纽

## RF/SDR 工具（开源）
> `[repo]` = 开源仓库地址。全部仓库集中索引见 [repos.md](repos.md)。

- [gr-satellites](https://github.com/daniestevez/gr-satellites) `[repo]` — GNU Radio 业余卫星遥测解码器合集（Daniel Estévez 维护）
- [SatNOGS](https://satnogs.org/) — 开源全球地面站网络
  - [SatNOGS DB](https://db.satnogs.org/) — 卫星/遥测数据库
  - [SatNOGS Network](https://network.satnogs.org/) — 存档观测数据
- [aptdec](https://github.com/Xerbo/aptdec) `[repo]` — NOAA APT 云图解码
- [sats-receiver](https://github.com/baskiton/sats-receiver) `[repo]` — 一体化 GNU Radio 接收
